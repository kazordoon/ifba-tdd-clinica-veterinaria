# ifba-tdd-clinica-veterinaria
[![Node.js CI](https://github.com/kazordoon/ifba-tdd-clinica-veterinaria/actions/workflows/node.js.yml/badge.svg)](https://github.com/kazordoon/ifba-tdd-clinica-veterinaria/actions/workflows/node.js.yml)

Trabalho acadêmico para a disciplina de Qualidade de Software com o objetivo em aplicar o **TDD** em uma clínica veterinária simples.

---

## ✅ Testes Aplicados

O trabalho foi desenvolvido em JavaScript com a suíte de testes utilizada sendo o **Jest**, seguindo os princípios do **TDD (Test-Driven Development)**.

### 🩺 Atendimentos

* [x] Rejeitar tipos de atendimento inválidos
* [x] Definir corretamente o tipo de atendimento se for válido
* [x] Definir o valor do atendimento de acordo com o tipo selecionado
* [x] Aplicar desconto de fidelidade de 10%
* [x] Não aplicar o desconto de fidelidade mais de uma vez

### 🐾 Animais

* [x] Definir o total gasto do animal após vários atendimentos consecutivos
* [x] Adicionar atendimentos ao histórico do animal
* [x] Aplicar o desconto de fidelidade após pelo menos 5 atendimentos anteriores
* [x] Não aplicar o desconto de fidelidade antes de atingir 5 atendimentos anteriores

### 🏥 Clínica

* [x] Adicionar um novo animal
* [x] Rejeitar o cadastro de um animal já existente
* [x] Adicionar uma lista de animais
* [x] Consultar um animal existente pelo ID
* [x] Rejeitar buscar um animal por um ID inexistente
* [x] Consultar um animal existente pelo nome
* [x] Rejeitar buscar um animal por um nome inexistente
* [x] Calcular o total gasto acumulado de todos os animais
* [x] Filtrar animais em que o total gasto esteja acima de determinado valor
* [x] Ordenar animais pelo total gasto em ordem decrescente
* [x] Remover animais que não possuem atendimentos registrados
